# Cheese Hub — Neon Website

Sitio estático (HTML, CSS y JS). No necesita instalar nada.

## Editar la página tú solo
1. Abre **editor.html** en tu navegador.
2. Cambia textos, categorías y tarjetas (añadir, borrar, reordenar).
3. Pulsa **DESCARGAR content.js**.
4. Reemplaza el `content.js` de esta carpeta con el que descargaste.
5. Abre **index.html** (o vuelve a subir la carpeta a tu hosting). Listo.

Tu trabajo se guarda como borrador en el navegador mientras editas.
Si algún día quieres editar a mano, `content.js` es texto simple.

## Archivos
- `index.html` estructura · `styles.css` colores y diseño (variables al inicio)
- `content.js` **todo el contenido editable** · `editor.html` editor visual
- `script.js` lógica de la página

## Colores
En `styles.css`, al inicio, cambia `--yellow`, `--red`, `--bg`, etc.
